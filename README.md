One-line apology from a smart speaker that misheard its owner — for the
make.fun bounty "Sorry, I Heard That Wrong".

## Run

```sh
node main.ts
```

This writes the entry to `entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

## Entry

> Sorry, I misheard 'plates' as 'planes' — your neighbour Ruth signed for 14 of them. I'm already aboard one.
